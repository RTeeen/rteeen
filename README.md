## About me

I'm a software engineer who likes owning a problem end to end. I've built SaaS products from the first schema to the last pixel: backend services and APIs, frontends and UI/UX, and the data platforms underneath that keep everything honest.

I care about software that's easy to reason about and pleasant to use: clear interfaces, boring and reliable infrastructure, tests that run against real systems, and failures that explain themselves.

## What I build

**SaaS products.** Taking an idea from prototype to something customers pay for and rely on: multi-tenant architecture, auth, billing and the boring bits that turn a startup into a real business.

**Backend systems.** APIs, services and integrations that handle real-world mess: paging, rate limits, retries, expiring tokens and jobs that pick up where they left off.

**Frontend and UI/UX.** Interfaces that feel obvious, from user flows and design to responsive, accessible front-end code.

**Data platforms.** Pipelines, warehouses and record matching that turn scattered data into something a product can trust.

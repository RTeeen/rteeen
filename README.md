## About me

I'm a data engineer who likes the unglamorous middle of the stack: the part between "we have data somewhere" and "we can actually trust this number." Most of my time goes into building ingestion pipelines, stitching records from different systems into a single view of a person, and keeping warehouses fast and boring.

I care about systems that are easy to reason about at 3am: idempotent loads, clear lineage, tests that run against real data, and failures that explain themselves.

## What I build

**Integrations.** Connectors that pull from APIs, files and event streams, handle paging, rate limits and expiring tokens, and pick up where they left off.

**Identity resolution.** Matching and merging records across sources into golden records, so one person stops showing up as five.

**Warehouse plumbing.** Models, incremental loads and the glue that keeps the same pipeline working across different warehouse engines.

**SaaS** Anything that helps your startup turn into a real business.
